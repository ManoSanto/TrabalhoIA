# FIFA Player Analysis & Machine Learning ⚽🤖

This project was developed for the **Artificial Intelligence (IA)** course at IPCA. It focuses on applying Data Science and Machine Learning techniques to a FIFA players dataset to extract insights and predict player attributes.

## 📁 Project Structure

The project is divided into three main notebooks:

1.  **Exploratory Data Analysis (EDA):** Initial data cleaning, visualization of player stats, and correlation analysis.
2.  **Regression Models:** Predicting player market value and ratings using regression algorithms.
3.  **Classification Models:** Categorizing players based on their skills, positions, or potential performance.

## 🚀 Key Features
* **Data Preprocessing:** Handling missing values, encoding categorical variables, and feature scaling.
* **Visualization:** Detailed charts using Matplotlib and Seaborn to understand player distributions.
* **Model Evaluation:** Performance metrics such as R², MSE (for regression) and Accuracy/F1-Score (for classification).

## 🛠️ Tech Stack
* **Language:** Python
* **Environment:** Jupyter Notebooks
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
